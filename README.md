# 🎵 NyxMusic

> Um aplicativo de música simples, moderno e focado em oferecer uma experiência prática para ouvir e organizar suas músicas.

## 📱 Sobre o NyxMusic

O **NyxMusic** é um aplicativo de música desenvolvido para oferecer recursos como pesquisa de músicas, reprodução, playlists, histórico e suporte a músicas para uso offline.

O projeto ainda está em desenvolvimento e novas funcionalidades e melhorias serão adicionadas ao longo do tempo.

## 🚀 Status do projeto

| Plataforma | Status |
|---|---|
| 🟢 Android | Disponível |
| 🍎 iOS | Em desenvolvimento |
| 🖥️ Windows | Futuramente |
| 🍎 macOS | Futuramente |

### Funcionalidades

- 🎵 Reprodução de músicas
- 🔎 Pesquisa de músicas
- 📋 Playlists
- 🕘 Histórico de reprodução
- 💾 Suporte a músicas offline
- 👤 Sistema de conta
- 📥 Download de músicas
- 🌙 Interface com modo escuro
